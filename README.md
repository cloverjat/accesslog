# AccessLog

Prototype auth + admin sign-in board.

## What it does
- Register / login / logout
- Forgot password + reset token flow
- Member dashboard
- Admin board: who signed in, what they did, from where (IP + city/country)

## Demo admin
- Email: `admin@accesslog.app`
- Password: `Admin123!`

## Important
This is a **browser-only prototype**. Users and logs live in `localStorage`.
A production version needs a server, a database, real email, and server-side sessions.
